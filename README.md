A single original funny one-liner, written by a small deterministic Python program to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty. The joke lands in one sentence: therapy meant to stop the narrator talking to himself now means paying someone to listen to him do it professionally.

## Run it

```sh
python3 main.py
```
